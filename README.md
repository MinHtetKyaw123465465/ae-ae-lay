# အဲအဲလေး — အရောင်းနှင့် ကိုယ်စားလှယ် စီမံခန့်ခွဲမှု

Laravel 12၊ React 19၊ TypeScript နှင့် MySQL 8.4 ဖြင့် တည်ဆောက်ထားသည်။ မျက်နှာပြင်၊ အမှားစာသားနှင့် နေ့ရက်/ငွေပမာဏများကို မြန်မာဘာသာဖြင့် ဖော်ပြထားပြီး ဖုန်းတွင် အောက်ခြေမီနူးနှင့် အော်ဒါကတ်များကို အသုံးပြုထားသည်။

## ပါဝင်သည့် လုပ်ဆောင်ချက်များ

- ပိုင်ရှင်တစ်ဦးနှင့် အတည်ပြုထားသော ကိုယ်စားလှယ်များ။ ဖုန်းနံပါတ်နှင့် စကားဝှက်ဖြင့် ဝင်ရောက်နိုင်သည်။
- လင့်ခ်မှ စာရင်းသွင်းခြင်း၊ ပိုင်ရှင်က လက်ခံခြင်း/ငြင်းပယ်ခြင်း။ စာရင်းသွင်းသူက မိမိကိုယ်ကို ပိုင်ရှင်အဖြစ် ပြောင်း၍မရ။
- ကုန်ပစ္စည်းထည့်/ပြင်ခြင်း၊ ဓာတ်ပုံတင်ခြင်း၊ ဈေးနှုန်း/ကော်မရှင်နှင့် လက်ကျန် သတ်မှတ်ခြင်း၊ ခေတ္တရောင်းချမှု ရပ်ခြင်း။
- ဝယ်သူအမည်၊ ဖုန်း၊ လိပ်စာ၊ အရေအတွက်နှင့် အော်ဒါတင်ခြင်း။ ဈေးနှုန်းနှင့် ကော်မရှင်ကို ဆာဗာက သတ်မှတ်ပြီး အော်ဒါတင်ချိန်တန်ဖိုးကို အမြဲထိန်းသိမ်းသည်။
- မပို့ရသေး၊ ပို့ပြီး၊ ပယ်ဖျက်ပြီး အခြေအနေများ။ ပယ်ဖျက်လျှင် လက်ကျန်ကို တစ်ကြိမ်သာ ပြန်ပေါင်းပေးသည်။
- ပို့ပြီးအော်ဒါများအတွက်သာ ကော်မရှင်။ ငွေရှင်းလက်ကျန်နှင့် ငွေရှင်းမှတ်တမ်း။ ကျန်ရှိငွေထက် ပိုပေးချေ၍မရ။
- အရောင်းအရေအတွက်ဖြင့် အဆင့်သတ်မှတ်ခြင်းနှင့် အပတ်/လ/နှစ် စစ်ထုတ်ခြင်း။
- အော်ဒါရှာဖွေခြင်း၊ အခြေအနေအလိုက် စစ်ထုတ်ခြင်းနှင့် စာရင်းဖိုင် ထုတ်ယူခြင်း။
- ကိုယ်စားလှယ်က မိမိအော်ဒါနှင့် ငွေရှင်းမှုများကိုသာ မြင်ရသည်။ အဆင့်စာရင်းတွင် အခြားဝယ်သူများ၏ ဖုန်း/လိပ်စာ မပါဝင်ပါ။

## လက်ရှိပတ်ဝန်းကျင်တွင် ဖွင့်ရန်

```bash
cd /workspace/ae-ae
npm run dev
```

မျက်နှာပြင် — http://localhost:5173

```bash
cd /workspace/ae-ae/backend
/workspace/.runtime/php artisan serve --host=127.0.0.1 --port=8000
```

MySQL ကို `aeae-mysql` ကွန်တိန်နာတွင် ဖွင့်ထားသည်။ ဒေတာကို Docker volume တွင် အမြဲသိမ်းဆည်းထားသည်။

```bash
cd /workspace/ae-ae
docker compose --env-file .env.docker up -d
```

ပထမဆုံးဖွင့်လျှင် အကောင့်ဝင်ဖောင်သာ ပြသည်။ ပိုင်ရှင် သို့မဟုတ် အတည်ပြုပြီးကိုယ်စားလှယ်အဖြစ် ဝင်ပြီးမှ လုပ်ငန်းစာရင်းများကို မြင်နိုင်သည်။ အကောင့်ထွက်လျှင် စာရင်းများကို ရှင်းလင်းပြီး အကောင့်ဝင်ဖောင်သို့ ပြန်ရောက်သည်။ စာရင်းသွင်းလင့်ခ်မှာ `/?register=1` ဖြစ်သည်။

အနှစ်ချုပ်၊ အော်ဒါနှင့် အရောင်းအဆင့်စာရင်းတွင် ယနေ့၊ မနေ့က၊ ပြီးခဲ့သည့် ၇ ရက်၊ ဒီတစ်ပတ်၊ ဒီတစ်လ၊ ပြီးခဲ့သည့်လ၊ ဒီတစ်နှစ်၊ အားလုံး သို့မဟုတ် စိတ်ကြိုက် စရက်/ဆုံးရက် ရွေးနိုင်သည်။ မြန်မာစံတော်ချိန်ဖြင့် စရက်နှင့် ဆုံးရက်နှစ်ရက်လုံး အပြည့်အစုံ ထည့်တွက်သည်။ အော်ဒါစာရင်းသည် အော်ဒါတင်သည့်ရက်ဖြင့်၊ ပို့ပြီးအရောင်းနှင့် အဆင့်စာရင်းသည် ပို့ပြီးမှတ်သားသည့်ရက်ဖြင့် စစ်ထုတ်သည်။ ကော်မရှင်ငွေရှင်းလက်ကျန်သည် စုစုပေါင်းလက်ကျန်ကို ဆက်လက်ပြသသည်။

ဖွံ့ဖြိုးရေးအတွက်သာ အသုံးပြုရန် နမူနာအကောင့်များ —

| အမျိုးအစား | ဖုန်းနံပါတ် | စကားဝှက် |
| --- | --- | --- |
| ပိုင်ရှင် | `09900000001` | `LocalFixture2026!` |
| ကိုယ်စားလှယ် | `09900000002` | `LocalFixture2026!` |

ဤအကောင့်များနှင့် နမူနာဝယ်သူဒေတာများကို အမှန်တကယ်လုပ်ငန်းအတွက် မသုံးပါနှင့်။ ကိုယ်စားလှယ်အသစ်အတွက် `/?register=1` လင့်ခ်ကို မျှဝေနိုင်သည်။

## ပတ်ဝန်းကျင်အသစ်တွင် ထည့်သွင်းရန်

PHP 8.4.1 နှင့်အထက်၊ Composer၊ Node.js 22.12 နှင့်အထက်၊ Docker သို့မဟုတ် MySQL 8 လိုအပ်သည်။ PHP တွင် PDO MySQL၊ mbstring၊ OpenSSL၊ XML၊ ctype၊ fileinfo တို့ ပါဝင်ရမည်။

```bash
npm ci
cp .env.docker.example .env.docker
# .env.docker တွင် ကိုယ်ပိုင် ကျပန်းစကားဝှက်နှစ်ခု ပြင်ပါ။
docker compose --env-file .env.docker up -d
cd backend
composer install
cp .env.example .env
php artisan key:generate
```

`backend/.env` တွင် `DB_CONNECTION=mysql`၊ `DB_HOST=127.0.0.1`၊ `DB_PORT=3306`၊ `DB_DATABASE=aeae`၊ `DB_USERNAME=aeae` နှင့် `.env.docker` နှင့် တူသော `DB_PASSWORD` ကို ဖြည့်ပါ။ `APP_LOCALE=my`၊ `APP_TIMEZONE=Asia/Yangon` နှင့် `SESSION_DRIVER=file` ထားပါ။

```bash
php artisan migrate
# ဖွံ့ဖြိုးရေးနမူနာ လိုအပ်မှသာ—
php artisan db:seed
```

## အမှန်တကယ် အသုံးပြုမည့် ဆာဗာအတွက်

သီးခြားဗလာဒေတာဘေ့စ်ကို အသုံးပြုပြီး နမူနာဒေတာ မထည့်ဘဲ အောက်ပါအတိုင်း ပိုင်ရှင်ဖန်တီးပါ။ ဖုန်းနှင့် စကားဝှက်ကို မေးမြန်းပေးသည်။ ပိုင်ရှင်ရှိပြီးလျှင် နောက်ထပ်ပိုင်ရှင် ဖန်တီးခြင်းကို ပိတ်ထားသည်။

```bash
php artisan migrate --force
php artisan app:create-owner
```

`APP_ENV=production`၊ `APP_DEBUG=false`၊ `APP_URL` ကို မိမိ HTTPS လိပ်စာ၊ `SESSION_SECURE_COOKIE=true` သတ်မှတ်ပါ။ လုပ်ငန်းအသုံးပြုမည့် အကောင့်များအတွက် နမူနာစကားဝှက် မသုံးပါနှင့်။

```bash
cd /workspace/ae-ae
npm run build
cd backend
php artisan config:cache
```

တည်ဆောက်ပြီးမျက်နှာပြင်နှင့် ဓာတ်ပုံ/စာလုံးဖိုင်များကို `backend/public` သို့ အလိုအလျောက် ကူးပေးသည်။ ဆာဗာ၏ ဝဘ်အမြစ်ကို ထိုဖိုလ်ဒါသို့ ချိတ်ဆက်ပါ။ API နှင့် မျက်နှာပြင်သည် မူလလိပ်စာတစ်ခုတည်းကို အသုံးပြုသည်။ ဆာဗာတွင် PHP-FPM/Nginx သို့မဟုတ် သင့်တော်သော Laravel ဝန်ဆောင်မှုကို အသုံးပြုပါ။ ဒေတာဘေ့စ်စကားဝှက်နှင့် `.env` ဖိုင်များကို အများပြည်သူထံ မမျှဝေပါနှင့်။

ငွေပေးချေမှုနှင့် ပို့ဆောင်ရေးဝန်ဆောင်မှု ချိတ်ဆက်မှု မပါဝင်ပါ။ ငွေရှင်းမှတ်တမ်းသည် အပြင်တွင် ငွေပေးချေပြီးနောက် မှတ်သားရန်ဖြစ်ပြီး အက်ပ်မှ ငွေအမှန်တကယ် လွှဲပေးခြင်း မရှိပါ။

## စမ်းသပ်ခြင်း

```bash
npm run build
cd backend
php artisan test
cd ..
# ရှေ့မျက်နှာပြင်နှင့် Laravel ဆာဗာ၊ နမူနာဒေတာပါ MySQL ဖွင့်ထားစဉ်—
npm test
```

Laravel စမ်းသပ်မှုများသည် မူလအားဖြင့် သီးခြားမှတ်ဉာဏ်ဒေတာဘေ့စ်ကို အသုံးပြုသည်။ MySQL ပေါ်တွင် စမ်းသပ်လျှင် `aeae_testing` ကဲ့သို့ **သီးခြားစမ်းသပ်ဒေတာဘေ့စ်** ကိုသာ သတ်မှတ်ပါ။ `RefreshDatabase` သုံးထားသောကြောင့် လုပ်ငန်းဒေတာဘေ့စ်ကို စမ်းသပ်မှုအတွက် မသတ်မှတ်ရပါ။

ဘရောက်ဇာစမ်းသပ်မှုတွင် နမူနာ MySQL ထဲသို့ စမ်းသပ်ကိုယ်စားလှယ်၊ အော်ဒါနှင့် ငွေရှင်းမှတ်တမ်းများ ထည့်သွင်းမည်။ နမူနာဒေတာပတ်ဝန်းကျင်တွင်သာ လုပ်ဆောင်ပါ။

## အရင်းအမြစ်များ

အမှတ်တံဆိပ်နှင့် ပန်းပုံများကို SVG ဖြင့် ရေးဆွဲထားသည်။ နမူနာကုန်ပစ္စည်းဓာတ်ပုံများသည် Unsplash မှဖြစ်ပြီး မိမိပစ္စည်းဓာတ်ပုံများနှင့် အစားထိုးနိုင်သည်။ Noto Sans Myanmar စာလုံးကို SIL Open Font License အောက်တွင် စာလုံးဖိုင်အဖြစ် ထည့်သွင်းထားသောကြောင့် Google Fonts ကို အသုံးပြုချိန်တိုင်း ချိတ်ဆက်ရန် မလိုပါ။

## စာရင်းရှည်များနှင့် ရေရှည်ထိန်းသိမ်းမှု

အော်ဒါ၊ ပစ္စည်း၊ ကိုယ်စားလှယ်၊ ကော်မရှင်လက်ကျန်၊ ငွေရှင်းမှတ်တမ်းနှင့် အဆင့်စာရင်းများကို ဆာဗာဘက်တွင် စစ်ထုတ်ပြီး စာမျက်နှာခွဲထားသည်။ မူလတစ်မျက်နှာ ၁၀ ခုဖြစ်ပြီး ၂၀ သို့မဟုတ် ၅၀ ခု ရွေးနိုင်သည်။ အော်ဒါတင်ဖောင်ရှိ ပစ္စည်း/ကိုယ်စားလှယ်ရွေးချယ်မှုတွင်လည်း ရှာဖွေခြင်းနှင့် စာမျက်နှာခွဲခြင်း ပါဝင်သည်။ စုစုပေါင်းငွေနှင့် ကော်မရှင်သည် လက်ရှိစာမျက်နှာတစ်ခုတည်းမှ တွက်ထားခြင်း မဟုတ်ပါ။ စာရင်းဖိုင်ထုတ်ယူမှုသည် ရွေးထားသော ရက်နှင့် အခြေအနေကိုက်ညီသည့် စာရင်းအားလုံးကို အပိုင်းလိုက် ထုတ်ပေးသည်။

အော်ဒါနှင့် ငွေရှင်းဖောင်တွင် တောင်းဆိုမှုအမှတ် ပါဝင်သောကြောင့် ချိတ်ဆက်မှုပြတ်ပြီး ထပ်တင်လျှင် အမှတ်တူစာရင်းကို နှစ်ခါမသိမ်းပါ။ API ကို အခြားစနစ်မှ ခေါ်သုံးလျှင်လည်း UUID `request_key` ကို တစ်ကြိမ်တင်မှုအတွက် တစ်ခုထုတ်ပြီး ထပ်တောင်းဆိုမှုတိုင်းတွင် ထိုအမှတ်ကိုပင် ပြန်ပို့ပါ။ ပစ္စည်းပြင်ဆင်မှုအတွက် လက်ရှိ `lock_version` ကို ပို့ရသည်။ အော်ဒါတင်ချိန် `expected_price` နှင့် `expected_commission` ပို့ခြင်းဖြင့် ဖောင်ဖွင့်ပြီးနောက် ဈေးပြောင်းသွားလျှင် ပြန်စစ်ဆေးရန် တားပေးသည်။

ဆက်တင်များမှ လက်ရှိစကားဝှက်ဖြင့် စကားဝှက်ပြောင်းနိုင်ပြီး အခြားစက်များရှိ အကောင့်ဝင်ထားမှုများ ပယ်ဖျက်မည်။ စကားဝှက်မေ့သွားလျှင် ယုံကြည်ရသော ဆာဗာကွန်ဆိုလ်မှသာ အောက်ပါအတိုင်း ပြင်ပါ။

```bash
php artisan app:reset-password
```

မှတ်တမ်းဖိုင်များကို နေ့အလိုက် သိမ်းပြီး မူလ ၁၄ ရက်အထိ ထိန်းထားသည်။ သက်တမ်းကုန် ဒေတာယာယီသိမ်းဆည်းမှုကို ရှင်းရန်—

```bash
php artisan app:prune-expired-cache
```

အမြဲတမ်းဆာဗာတွင် Laravel scheduler အတွက် မိနစ်တိုင်း `php artisan schedule:run` ကို ခေါ်ပေးပါ။ ထိုအခါ သက်တမ်းကုန်ယာယီဒေတာကို နေ့စဉ်ရှင်းပေးမည်။ ဒီစမ်းသပ်ပတ်ဝန်းကျင်တွင် အမြဲတမ်း cron ဝန်ဆောင်မှု မတပ်ဆင်ထားပါ။ အော်ဒါ၊ ငွေရှင်းမှတ်တမ်းနှင့် အကောင့်များကို အလိုအလျောက် မဖျက်ပါ။

Docker ဖြင့် လက်ရှိစမ်းသပ်တပ်ဆင်မှုအတွက် ဒေတာနှင့် ပစ္စည်းဓာတ်ပုံ အရန်သိမ်းရန်—

```bash
python scripts/backup-local.py /secure/path/for/backups
```

အရန်ဖိုင်များကို ဝဘ်အမြစ်အောက်တွင် သိမ်းခြင်းကို ပိတ်ထားပြီး ဖိုင်ခွင့်ပြုချက်ကို ပိုင်ရှင်သာ ဖတ်နိုင်အောင် သတ်မှတ်ထားသည်။ ပစ္စည်းဓာတ်ပုံများပါ တစ်ပြိုင်နက်ပြောင်းလဲနေသော လုပ်ငန်းဆာဗာတွင် စီစဉ်ထားသော ထိန်းသိမ်းချိန် သို့မဟုတ် hosting snapshot ဖြင့် ဒေတာနှင့် ဖိုင်များ ကိုက်ညီစွာ အရန်သိမ်းပါ။ အမြဲတမ်းအသုံးပြုရန် နေ့စဉ်အရန်၊ ဆာဗာပြင်ပ လုံခြုံသောသိမ်းဆည်းရာနှင့် ပုံမှန်ပြန်တင်စမ်းသပ်မှုကို သီးခြား စီစဉ်ရပါမည်။

## သီးခြား MySQL စမ်းသပ်မှု

`aeae_testing` ဒေတာဘေ့စ်နှင့် ထိုဒေတာဘေ့စ်အတွက် အသုံးပြုခွင့်ကို အရင်ဖန်တီးပါ။ အောက်ပါစာကြောင်းသည် ထိုစမ်းသပ်ဒေတာဘေ့စ်ကို ပြန်ဖန်တီးမည်ဖြစ်ပြီး လုပ်ငန်းဒေတာဘေ့စ်တွင် မသုံးရပါ။ စမ်းသပ်အခြေခံကလည်း မှတ်ဉာဏ်ဒေတာဘေ့စ် သို့မဟုတ် `_testing` ဖြင့်ဆုံးသော နာမည်ကိုသာ လက်ခံသည်။

```bash
python scripts/test-mysql.py
cd backend
DB_DATABASE=aeae_testing SESSION_COOKIE=aeae_audit_session CACHE_PREFIX=aeae_audit_ php artisan serve --port=8001
# အခြားကွန်ဆိုလ်တွင်—
TEST_BASE_URL=http://127.0.0.1:8001 npm test
```

တစ်ပြိုင်နက် အော်ဒါ/ငွေရှင်းတင်မှုနှင့် စာရင်း ၅၀,၀၀၀ ပါ စမ်းသပ်မှုများကို ထိုသီးခြားဒေတာဘေ့စ်တွင်သာ လုပ်ဆောင်ပါ။ ဘရောက်ဇာစမ်းသပ်မှုနှင့် တစ်ပြိုင်နက် မလုပ်ပါနှင့်။

```bash
DB_DATABASE=aeae_testing php tests/Support/concurrency.php
DB_DATABASE=aeae_testing php tests/Support/scale-benchmark.php
```

နောက်ဆုံး အချိန်တိုင်းတာမှုများကို `docs/scale-benchmark.json` တွင် တွေ့နိုင်သည်။ လုပ်ငန်းဒေတာနှင့် စကားဝှက်များ မပါသော ပရောဂျက်အရင်းအမြစ်ဖိုင်ကို ပြန်ထုတ်ရန် `python scripts/package-source.py` ကို အသုံးပြုပါ။

## အကောင့်မှတ်ထားခြင်း၊ အက်ပ်ထည့်သွင်းခြင်းနှင့် အသိပေးချက်

ဝင်ရောက်ချိန် `အကောင့်မှတ်ထားမည်` ရွေးလျှင် ရက် ၃၀ အထိ လုံခြုံသော ကွတ်ကီးဖြင့် မှတ်ထားသည်။ စကားဝှက်ကို ဘရောက်ဇာသိမ်းဆည်းရာတွင် မသိမ်းပါ။ အကောင့်ထွက်လျှင် မှတ်ထားမှုနှင့် လက်ရှိစက်၏ အသိပေးချက်ချိတ်ဆက်မှုကို ပယ်ဖျက်သည်။

ဆက်တင်တွင် အက်ပ်ထည့်သွင်းခြင်းနှင့် ဖုန်းအသိပေးချက် ဖွင့်/ပိတ်နိုင်သည်။ iPhone/iPad တွင် Safari မျှဝေမီနူးမှ ပင်မမျက်နှာပြင်သို့ ထည့်ပြီးမှ အသိပေးချက်ခွင့်ပြုပါ (iOS/iPadOS 16.4 နှင့်အထက်)။ HTTPS လိုအပ်သည်။ အော်ဒါအသစ်၊ အော်ဒါပို့ပြီး/ပယ်ဖျက်ပြီး၊ အကောင့်အတည်ပြုမှုနှင့် ကော်မရှင်ငွေရှင်းမှုတို့ကို သက်ဆိုင်သူ၏ ခေါင်းလောင်းစာရင်းတွင် ပြသည်။ ဖုန်းအသိပေးချက်တွင် ဝယ်သူလိပ်စာနှင့် ဖုန်းနံပါတ် မပါဝင်ပါ။

ဆာဗာအသစ်တွင် အမြဲတမ်း HTTPS လိပ်စာကို `APP_URL` နှင့် `VAPID_SUBJECT` တွင် သတ်မှတ်ပြီး—

```bash
php artisan migrate --force
php artisan app:generate-push-keys
php artisan queue:work --sleep=3 --tries=3 --timeout=60
```

အမြဲတမ်းအသုံးပြုရာတွင် queue worker ကို Supervisor/systemd ဖြင့် ဆက်လက်လည်ပတ်စေပါ။ ပြင်ဆင်တင်ပြီးလျှင် `php artisan queue:restart` ခေါ်ပါ။ လျှို့ဝှက် VAPID key ကို မမျှဝေပါနှင့်။ Key အသစ်ပြန်ထုတ်လျှင် စက်တိုင်း အသိပေးချက်ပြန်ဖွင့်ရမည်။ အက်ပ်ပိတ်ထားချိန် အသိပေးချက်အတွက် ဝင်ရောက်မှု သက်တမ်းရှိရမည်ဖြစ်၍ ကိုယ်ပိုင်ဖုန်းတွင် အကောင့်မှတ်ထားခြင်းကို ရွေးနိုင်သည်။

အင်တာနက်ပြတ်ချိန်တွင် ချိတ်ဆက်မှုမရှိကြောင်းသာ ပြသည်။ အော်ဒါ၊ ဝယ်သူဒေတာနှင့် API တုံ့ပြန်ချက်များကို အော့ဖ်လိုင်းအတွက် မသိမ်းပါ။ ယာယီစမ်းသပ်လင့်ခ် ပြောင်းသွားလျှင် အက်ပ်ကို လင့်ခ်အသစ်မှ ပြန်ထည့်ရန် လိုအပ်သည်။
